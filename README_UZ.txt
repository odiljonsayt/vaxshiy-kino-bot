VAXSHIY KINO BOT — ISHGA TUSHIRISH

Bot nima qiladi?
- Foydalanuvchi /start bosganda xush kelibsiz xabarini ko‘rsatadi.
- “KANALGA O‘TISH” tugmasi https://t.me/vaxshiy_kino manzilini ochadi.
- /help buyrug‘i yordam ko‘rsatadi.

1. BOTFATHER ORQALI BOT YARATING
- Telegramda @BotFather ni oching.
- /newbot yuboring.
- Bot nomini kiriting: Vaxshiy Kino
- Username tanlang. Masalan, VaxshiyKinoBot (bo‘sh bo‘lishi shart).
- BotFather bergan TOKENni oling. Tokenni hech kimga yubormang.

2. PYTHON O‘RNATING
- Kompyuterda Python 3.10 yoki undan yangi versiya bo‘lsin.
- Ushbu papkani oching.
- Terminal/CMD oynasida shu papkaga o‘ting.

3. KUTUBXONALARNI O‘RNATING
    pip install -r requirements.txt

4. TOKENNI SOZLANG
- .env.example faylidan nusxa oling va nusxasini .env deb nomlang.
- .env ichidagi BOT_TOKEN= dan keyin BotFather bergan tokenni yozing.
- Tokenni boshqalarga ko‘rsatmang va GitHub'ga yuklamang.

5. BOTNI ISHGA TUSHIRING
    python -m pip install python-dotenv
    python bot.py

Keyin Telegramda o‘z botingizni ochib /start yuboring.

- Bot ishlashi uchun kompyuter yoki hostingda bot.py doim ish holatida turishi kerak.
